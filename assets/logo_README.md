# Tu logo (opcional)

Si quieres que tu logo aparezca en la esquina de cada tarjeta de versículo:

1. Prepara tu logo como PNG, idealmente con fondo transparente
2. Súbelo a esta misma carpeta `assets/` con el nombre exacto: `logo.png`
3. Listo — el script lo detecta solo y lo agrega automáticamente

Si no subes nada, las tarjetas se generan igual, simplemente sin logo.
