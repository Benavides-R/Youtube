Política de Privacidad

Última actualización: 2026

¿Qué es esta aplicación?

"YouTube Automático" es una herramienta de uso estrictamente personal, desarrollada y operada por su único usuario, para automatizar la subida de videos a canales de YouTube propios del desarrollador.

¿Qué datos accede?

La aplicación utiliza la API de YouTube Data (v3) únicamente para subir videos y miniaturas a los canales de YouTube que le pertenecen al desarrollador. No accede a datos de ningún otro usuario ni de ningún canal ajeno.

¿Cómo se almacenan los datos?

Las credenciales de acceso (tokens de OAuth) se almacenan de forma encriptada como "Secrets" dentro de GitHub Actions, una plataforma segura de terceros (GitHub/Microsoft). Nunca se almacenan en texto plano ni se comparten con ningún tercero.

¿Se comparten datos con terceros?

No. Ningún dato accedido a través de la API de YouTube se vende, comparte, ni transfiere a terceros bajo ninguna circunstancia.
